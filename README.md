# 知音漫卷

> 把插图放回文字里，把朗读对上句子。

**知音漫卷**是一个以桌面浏览器为主的阅读 Web 应用。导入 EPUB / TXT / Markdown 后，
系统在浏览器内完成解析，正文以图文混排方式滚动阅读，并支持逐句高亮跟读；
阅读进度与书签按设备记录、跨端同步，冲突时两份都保留。

软件工程课程设计 · 第一组 · 当前版本 **1.3.0**

[功能](#功能) · [快速开始](#快速开始) · [使用说明](#使用说明) · [技术栈](#技术栈) · [测试](#测试) · [文档](#文档)

## 功能

| 能力 | 说明 |
|---|---|
| **图文混排** | 插图内联在原文引用位置，进入视口才加载，离开视口释放内存 |
| **逐句跟读** | 一句一句念，念到哪句哪句亮；高亮由真实播放结束事件驱动 |
| **跨设备续读** | 进度按设备记录；新设备打开时恢复到最近位置，且不会被拉回更早的位置 |
| **冲突不丢数据** | 书签冲突默认“两份都保留”，由读者选择保留哪一份 |
| **长文档不卡** | 超过 150 段自动窗口化渲染，500 段实测只保留 25～38 个段落节点 |
| **本地优先** | 解析、图片缓存、阅读设置都在浏览器完成；服务端只负责存储与同步 |

必须真实跑通的三项：**逐句高亮跟读**、**跨设备同步 + 冲突处理**、**图文混排 + 图片懒加载**。

## 快速开始

### 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位）；服务端也可在 macOS / Linux 上跑 |
| 运行时 | Node.js **20 或更高版本**（含 npm） |
| 浏览器 | Chrome / Edge / Firefox / Safari 的近年版本 |
| 网络 | 首次安装依赖需要联网；之后可离线运行 |

不需要 Docker、Python 或数据库服务器。

### 一键启动

双击项目根目录的 **`start.bat`**。它会自动检查 Node、安装依赖、建库并写入演示数据、
启动前后端、打开浏览器。

### 手动启动

需要两个终端：

```bash
# 终端 1 —— 服务端（3000）
cd server
npm install          # 首次
npm run seed         # 首次：建库 + 演示数据
npm run server

# 终端 2 —— 前端（5173）
cd client
npm install          # 首次
npm run dev
```

浏览器打开 **http://localhost:5173**。

### 演示账号

```
账号：demo@example.com
密码：demo12345
```

登录后书架上有《人间词话》与《书签压力册》两本演示书。也可以自行注册，
账号填手机号或邮箱、密码至少 8 位。

> ⚠️ 修改 `server/sql/schema.sql` 的列或表后必须重建数据库：
> `cd server && npm run db:reset && npm run seed`。重建会清空已导入的书、图片与头像。

## 使用说明

### 界面与路由

| 界面 | 怎么进 |
|---|---|
| 引导界面 | 打开应用的第一屏；`/` 与未知路径都落到这里 |
| 登录 / 注册 | 引导页点「开始使用」，或访问 `/login` |
| 书架 | 登录后进入，或访问 `/shelf` |
| 阅读器 | 在书架点任意一本书，或访问 `/read/:docId` |
| 阅读时长 | 书架左侧「阅读时长」，或访问 `/stats` |
| 个人主页 | 书架右上角头像，或访问 `/profile` |

播放控制条、阅读设置、书签面板、冲突对话框都嵌在阅读器内，不是独立页面。

### 导入文档

书架右上角 **「导入文档」**：

| 格式 | 解析方式 |
|---|---|
| **EPUB** | 完整支持封面、章节、插图；按 spine 顺序拼章节 |
| **TXT** | 按空行分段；`第 X 章 / 卷 / 节` 识别为标题 |
| **Markdown** | 标题、段落、图片都会解析 |

- 解析全部在浏览器内完成，结果再上传服务端；**单文件上限 500MB**。
- 同一本书重复导入会被拒绝，并提供「打开它」按钮。
- 导入时图片二进制不上传，只写进浏览器 IndexedDB；阅读时首次进入视口才补传到服务端。
- 解析在浏览器内存中完成，几百 MB 的书会占用大量内存，演示用的书都在几 MB 量级。

### 阅读

- 正文最大宽度 720px 居中滚动。
- 右上角「目录」打开侧边抽屉，当前章节高亮，点击跳转，Esc 或点外部收起。
- 图片加载中显示占位块；失败显示「图片不可用」和重试入口。
- 超过 150 段自动启用窗口化渲染。

### 阅读设置

右上角「设置」打开面板，四项设置都会记住：

| 设置 | 选项 |
|---|---|
| 主题 | 白天 / 夜晚，夜晚模式整个应用一起换色 |
| 字号 | 14～24px 六档，正文与标题一起缩放 |
| 翻页方式 | 滚动（默认）/ 点击翻页 |
| 阅读背景 | 本地图片，仅存本机，上限 8MB |

点击翻页时，正文左侧回上一屏、右侧翻下一屏；点句子仍然会跳到该句。

### 逐句跟读

底部播放条：

| 操作 | 效果 |
|---|---|
| 跟读 / 暂停 | 开始或停下 |
| 上一句 / 下一句 | 移动游标，暂停时也能用 |
| 语速 | 0.5x～2.0x，改完从下一句生效 |
| 音色 | 已安装的可选，未安装的置灰并提示「需安装离线音色包」 |
| 点正文任意句子 | 停在那一句，出现「继续跟读」提示 |

高亮位置与真实播放事件严格对应，句子会自动滚到屏幕中间。

**语音引擎**默认是本地 Kokoro；没有安装时自动降级为浏览器原生发声，
底部显示「已降级为浏览器发声」，跟读全链路照常可用。

### 书签与收藏

- 阅读器右上角「书签」：加当前位置、跳转、重命名、删除。
- 默认名由系统生成（章节标题 + 正文前 10 个字），可以修改。
- 在「拖动顺序」下可长按拖动排序；列表支持分页与按创建时间 / 章节排序。
- 书架左侧「我的书签」提供跨文档总览。
- 书封左上角的 ☆ 是收藏；「我的收藏」只列收藏过的书。

### 同步与冲突

- 进度与书签自动同步；书架左下角显示 `已同步` / `待同步 N 条` / `同步中…` / `有冲突待处理`。
- 旁边的 **「一键同步」** 会把离线队列里的变更一次补报，并读回未决冲突。
- 进度不会倒退：别的设备读得更前就用它；本机读得更前则保留本机的。
- 书签冲突时，阅读器右上角出现红色角标，点开可选择：
  - **保留本机**
  - **保留云端**
  - **两份都保留**（服务端为新记录分配 id，本机那份名字带「（本机）」后缀）
- 一端删除、另一端修改时保留修改，并标注「该设备曾删除此书签」。
- 数据不会被静默丢弃；冲突记录落库，刷新页面后仍能读回。

> 两个浏览器窗口共享 localStorage，`deviceId` 相同。真跨设备演示请用两台机器。

### 阅读时长与个人主页

- 阅读时长统计累计、今天、本周与按书排行；只统计阅读界面可见且窗口聚焦的时间。
- 个人主页可上传 / 移除头像（png / jpg / webp，≤2MB）、修改昵称（≤32 字）。

### 更新提示

- Android 壳：发现强制更新时弹出不可关闭的更新窗口。
- 手机 / 平板网页版：顶部显示「发现新版本 / 立即刷新」，不打断阅读。

## 常见问题

| 问题 | 处理 |
|---|---|
| 页面显示「无法连接到服务端」 | 服务端没起来；检查 3000 端口或重新运行 `start.bat` |
| 跟读没有声音 | 看是否提示「已降级为浏览器发声」；检查系统音量和标签页静音 |
| 图片显示「图片不可用」 | 图片是懒上传的；回到导入设备打开该书并滚到该图位置即可补传 |
| 账号被锁定 | 连续输错 5 次会锁 15 分钟，等待或换账号 |
| 想清空数据重来 | 关掉服务，删除 `server/data/`，再执行 `npm run seed` |
| 长文档滚动卡 | 超过 150 段会自动窗口化；同屏插图过多仍可能吃内存 |

## 技术栈

| 层 | 选型 |
|---|---|
| 前端 | React 18 + Vite + TypeScript + react-router-dom |
| 样式 | 单文件 `client/src/app.css`，无 UI 框架 |
| 后端 | Node.js 20+ + Fastify 4 + TypeScript |
| 数据库 | SQLite（`better-sqlite3 ^12.11.1`），13 张表 |
| 解析 | `epub.js`（只取解析结果）、`marked`、自写 TXT 解析 |
| 语音 | 本地 Kokoro（OpenAI 兼容）/ Edge 在线语音 / 浏览器 `SpeechSynthesis` |
| 原生壳 | Capacitor Android |

架构、数据模型、接口与关键流程见 [`docs/system-design.md`](./docs/system-design.md)。

## 已知限制

- 暂停是「停掉当前句」，恢复时该句从头念，不是句中断点续播。
- 两个浏览器窗口共享 `deviceId`；真跨设备同步需两台机器。
- 未决冲突只在阅读器读回，书架还没接入。
- `POST /api/sync` 每次整体比较所有书签，未做真正增量游标。
- `Idempotency-Key` 只覆盖 `/api/sync`。
- 图片只在实际阅读时懒上传；从未打开过的书，服务端没有图片副本。
- `epubjs` 300KB+ 打进主包，未做代码分割。
- 完整移动端响应式改版未并入当前主线。

## 本地语音引擎（可选）

装并启动 [Kokoro-FastAPI](https://github.com/remsky/Kokoro-FastAPI)（默认 8880 端口）即可，
服务端会自动发现并切换默认引擎，不用改代码。

自定义地址时，启动服务端前设置：

```
TTS_BASE_URL=http://127.0.0.1:8880/v1
TTS_API_KEY=
TTS_MODEL=kokoro
TTS_TIMEOUT_MS=20000
```

没有 GPU 时，可设 `TTS_PROVIDER=edge` 改用微软 Edge 在线语音；
任何提供 OpenAI 兼容 `/v1/audio/speech` 的服务都可以替换进来。
