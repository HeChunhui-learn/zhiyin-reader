## 4.2 类设计

知音漫卷系统的设计类图见图4-7，图中类按体系结构分为界面层、业务逻辑层、接口层与数据层。界面层包括：“GuidingUI”（属性：slideIndex、cards，操作：nextSlide()、startUsing()、goLogin()）、“LoginView”（属性：account、password、rememberMe、errorMsg、loading，操作：submitLogin(account, password)、submitRegister(account, password)、switchTab(tab)、oauthLogin(provider)、setSession(userInfo, token)）、“LibraryView”（属性：keyword、cards、syncState、parseProgress，操作：openDocument(docId)、importDocument(file)、search(keyword)、addToShelf(document)）、“ReaderView”（属性：currentDocument、scrollPosition、highlightCursor、imagePlaceholders，操作：renderDocument(doc)、renderImage(blob)、highlightSentence(index)、scrollToAnchor(anchor)、loadImage(imageRef)、locateTo(anchor)、onReadAlongFinished(lastIndex)）、“PlaybackBar”（属性：playbackState、playbackRate、voice、currentIndex，操作：startReadAlong(sentenceList, voice, rate)、holdCursor(i)、resumeFrom(i)、pauseScroll()）、“ConflictDialog”（属性：conflictList、selection，操作：showConflicts(conflictList)、chooseResolution(conflictId, side)、applyAndMerge()、deferLater()、dismiss()）。业务逻辑层包括：“AuthController”（属性：session，操作：login(account, password)、issueJWT(userId)）、“DocumentParser”（属性：fileType，操作：parse(file)、dispatchParser(format)、matchImageRefs(text)）、“RenderController”（属性：renderQueue，操作：render(doc)、buildPlaceholders(doc)、observeImages(container)、loadImage(url)、recycleInvisible()、renderRetryPlaceholder(url)）、“ReadAlongController”（属性：audioQueue、currentIndex，操作：startReadAlong(sentenceList, voice, rate)、splitSentences(text)、advanceCursor(i)、holdCursor(i)、resumeFrom(i)）、“SyncController”（属性：syncState、lastSyncTime，操作：syncProgress(docId, deviceId)、merge(local, remote)、updateAnchor(chapter, paragraph, offset)、fallbackToChapterStart(chapter)、commitChanges(delta, baseVersion)、saveConflict(localDelta, remoteChanges)、tryAutoMerge(localDelta, remoteChanges)、showConflicts(conflictList)、deferConflict(recordId)、enqueuePendingChange(change)）、“BookmarkController”（属性：bookmarkList、activeDocId、pendingQueue，操作：addBookmark(docId, anchor, name)、renameBookmark(bookmarkId, name, baseVersion)、moveBookmark(bookmarkId, anchor, baseVersion)、deleteBookmark(bookmarkId, baseVersion)、listBookmarks(docId, includeDeleted)、validateAnchor(anchor)、enqueuePendingChange(change)）。接口层包括：“ServerAPI”（fetchImage(url)）、“LocalStoreAPI”（getImageBlob(cacheKey)、putCache(cacheKey, imageBlob)）、“CloudStorageAPI”（fetchUser(account)、listProgressByDocument(userId, docId)、commitChanges(delta, baseVersion)）、“ObjectStorageAPI”（uploadResource(file, images)）、“TTSEngineAPI”（synthesize(text, voice, rate)）、“AIChatService”（ask(question, context)），以及数据访问接口“DataAccessLibrary”（见4.3.2）。其中 DataAccessLibrary 是业务逻辑层访问数据层的唯一入口，逻辑上归属于数据层，在设计类图中与外部系统接口同列绘制。数据层包括：“User”（属性：userId、account、passwordHash、salt、nickname、createdAt、lastLogin，操作：verifyPassword(password, salt, passwordHash)）、“Document”（属性：docId、ownerId、fileName、fileFormat、title、author、contentHash、importedAt、resourceUrl，操作：createDocument(meta, paragraphs, imageRefs)、setResourceUrl(resourceUrl)）、“Paragraph”、“Sentence”（操作：createSentences(offsets)）、“AudioClip”、“ImageResource”（操作：isCached()）、“ReadingProgress”（操作：loadLocal(docId)）、“SyncRecord”（操作：saveConflict(localDelta, remoteChanges)、updateState(state)、enqueuePendingChange(change)）、“Bookmark”（属性：bookmarkId、docId、anchor、name、version、deletedAt，操作：createBookmark(docId, anchor, name)、rename(name)、moveTo(anchor)、markDeleted(deviceId)、isAnchorValid(document)）。类之间关系：LoginView 依赖 AuthController、LibraryView 依赖 DocumentParser、ReaderView 依赖 RenderController 与 SyncController、PlaybackBar 依赖 ReadAlongController；AuthController、DocumentParser、ReadAlongController 与 SyncController 依赖 DataAccessLibrary 完成持久化；AuthController 依赖 CloudStorageAPI 与 User，DocumentParser 依赖 ObjectStorageAPI 与 Document，RenderController 依赖 ServerAPI、LocalStoreAPI 与 ImageResource，ReadAlongController 依赖 TTSEngineAPI、Sentence 与 AudioClip，SyncController 依赖 ReadingProgress、SyncRecord、ConflictDialog 与 CloudStorageAPI；ReaderView 与 LibraryView 依赖 BookmarkController，BookmarkController 依赖 Bookmark、ConflictDialog 与 DataAccessLibrary。
