# 界面版面稿（文字版）

> **本文件是人写的，不是从 docx 抽的。** 04 §3.1 原有四张「界面外观设计」图是位图，转 Markdown 后完全丢失，而这个损失**不可替代**——表3-1~3-4 只列了元素清单，列不出版面结构。
> 下面的版面是按 04 §3.1 的正文描述 + 表3-1~3-4 的元素清单**推出来的**，请你对着原 docx 里的图核一遍，改完再让 Claude Code 用。
> 标 ⚠ 的是正文里没写、由我补的，最需要你确认。

通用约定：

- 目标窗口宽度 **≥ 1280px**，居中布局，最小宽度 1024px
- 全局字体：`system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`
- 配色：主色 `#2F6FED`，正文 `#1F2328`，次要文字 `#6B7280`，分割线 `#E5E7EB`，页面底 `#FFFFFF`
- 所有异步操作要有加载态；所有失败要有中文提示条，**不允许白屏**

## 1. 引导界面（`GuidingUI`，路由 `/guide`）

**依据**：04 §3.1.1「界面由标题区、插图占位区、能力卡片区、轮播指示点与主操作按钮构成」+ 表3-1

**版面**：整页居中单列，上下结构，垂直居中于视口

| 区域 | 内容 | 元素类型 |
|---|---|---|
| 顶部 | 引导页标题「知音漫卷」+ 副标题（一句话定位） | 静态元素 |
| 中部 | 品牌插图占位区（灰色圆角块，按引导页序号换图） | 动态元素 |
| 中部 | 能力卡片区：横向 3 张卡片，每张含图标 + 标题 + 一句说明。内容随引导页切换而刷新 | 动态元素 |

**交互**：左右滑动手势 / 点击指示点切换引导页（轮播滑动手势属输入元素）。

**命令元素**（对应类操作，签名固定）：`nextSlide(): void`、`startUsing(): void`、`goLogin(): void`

⚠ 引导页共 3 页，这是从 3 个轮播指示点推的。

## 2. 登录／注册界面（`LoginView`，路由 `/login`）

**依据**：04 §3.1.2「左侧为品牌介绍区，右侧为表单卡片」+ 表3-2

**版面**：整页左右两栏，左栏约占 45%，右栏约占 55%

| 区域 | 内容 | 元素类型 |
|---|---|---|
| 左栏 | 品牌介绍区：产品名 + 一句宣传语 + 插图占位 | 静态元素 |
| 右栏 | 表单卡片（白色圆角卡片，居中，宽约 400px） | — |

表单卡片自上而下：

1. 页签：「登录」/「注册」（`switchTab(tab)` 切换）
2. 账号输入框，占位文本提示「手机号／邮箱」——输入元素
3. 密码输入框，掩码显示（以 `•` 显示）——输入元素
4. 「记住我」复选框——输入元素

## 3. 书架界面（`LibraryView`，路由 `/shelf`）

**依据**：04 §3.1.3「顶部栏提供检索与"导入文档"入口，左侧导航栏按"全部书籍、最近阅读、我的书签、离线文档"分类，主区域以卡片栅格展示…左下角常驻显示同步状态标识」+ 表3-3

**版面**：顶部栏 + 左右两栏（左导航 200px 固定，右主区自适应）

| 区域 | 内容 | 元素类型 |
|---|---|---|
| 顶部栏 | 左侧产品名；中间搜索框（占位「书名／作者／正文全文检索」）；右侧「导入文档」按钮 | 静态 + 输入元素 |
| 左侧导航 | 「全部书籍」「最近阅读」「我的书签」「离线文档」四项，可切换 | 静态元素 |
| 左下角 | 同步状态标识：未同步／同步中／已同步／冲突（四态，不同颜色） | 动态元素 |
| 主区域 | 书籍卡片栅格，每行 4 张（宽 ≥1280 时）；每张卡片含封面占位、标题、作者、阅读进度条、右上角「⋯」快捷操作 | 动态元素 |

## 4. 阅读界面（`ReaderView`，路由 `/read/:docId`）

**依据**：04 §3.1.4「界面由顶部工具栏、正文排版区与底部播放控制条构成」+ 表3-4

**版面**：顶部工具栏（约 48px）+ 正文区（滚动）+ 底部播放控制条（约 64px，常驻）

| 区域 | 内容 | 元素类型 |
|---|---|---|
| 顶部工具栏 | 左「返回」按钮 → `/shelf`；中间书名；右侧依次：「目录」按钮、「同步冲突」按钮（冲突时红色角标） | 静态 + 命令元素 |
| 正文区 | 单栏，最大宽度 720px 居中；章节标题居中加粗；段落首行缩进 2 字符；行高 1.8 | 静态元素 |
| 正文区 | 正文中的图片在引用位置**内联**呈现，宽度撑满正文栏 | 静态元素 |
| 正文区 | 图片骨架占位（灰底块 + 加载动画），加载失败显示「加载失败，点击重试」 | 动态元素 |
| 正文区 | 高亮游标：正在朗读的句子加背景色（`#FFF3BF`），并自动滚动跟随 | 动态元素 |
| 底部条 | `PlaybackBar`，见下 | — |

**命令元素**：`renderDocument(doc)`、`highlightSentence(index)`、`scrollToAnchor(anchor)`、`loadImage(imageRef)`

**输入元素**：滚动位置——作为阅读进度锚点上报（滚动停止 500ms 后上报一次）

### 4.1 播放控制条（`PlaybackBar`，嵌入阅读界面底部）

从左到右：

1. 「上一句」按钮
2. 「播放／暂停」按钮（主按钮，最大）
3. 「下一句」按钮
4. 语速下拉：0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x，默认 1.0x
5. 音色下拉：从服务端拉取可用音色列表，默认为第一项
6. 右侧：当前进度文字「第 12 / 208 句」

**命令元素**：`startReadAlong(sentenceList, voice, rate)`、`holdCursor(i)`、`resumeFrom(i)`、`pauseScroll()`

⚠ **接管行为**：读者在跟读中手动滚动或点击任意句子时，暂停自动滚动但保留高亮位置，播放到该句结束后暂停；点击「继续跟读」平滑接管。这是 04 §4.1.4 写了但没给 UI 的，你确认一下这样是否合适。

## 5. 冲突对话框（`ConflictDialog`，模态）

> ⚠ **04 的界面设计里完全没有这个界面**（界面流也只有五个界面，漏了它）。下面这份是我拟的，**必须你确认**，尤其第 3 点。

**版面**：居中模态，宽约 640px，遮罩 `rgba(0,0,0,.4)`，不可点遮罩关闭

| 区域 | 内容 |
|---|---|
| 标题 | 「发现 N 处同步冲突」 |
| 列表 | 逐条展示：冲突类型（如「同一书签被两端重命名」）+ 双方差异对比（左右两栏，各自显示设备名与内容） |
| 每条的操作 | 单选框：保留本机 / 保留云端 / **两份都保留** |
| 底部 | 「稍后处理」（关闭模态，保留冲突角标） / 「应用」（提交裁决） |

**命令元素**：`showConflicts(conflictList)`、`chooseResolution(conflictId, side)`、`applyAndMerge()`、`deferLater()`、`dismiss()`

**关键行为**（来自 CLAUDE.md 裁决 3）：

- 选「两份都保留」时，**由服务端**生成第二条记录的 `bookmark_id`，客户端以响应为准覆盖本地
- 选「稍后处理」时冲突不消失，顶部工具栏的「同步冲突」按钮保留红色角标
- **未处理的冲突不阻止继续阅读**

## 6. 界面流（修正版）

04 §3.2 的界面流漏了引导页和冲突页，实际应为：

```
/guide ──开始使用──→ /login ──登录成功──→ /shelf
   │                                        │  ▲
   └──直接登录──────────────────────────────┘  │
                                               │
                       点卡片                  │ 返回
        /shelf ────────────────────────→ /read/:docId
          │                                    │
          │ 导入文档（弹文件选择框）             │ 同步冲突（红色角标）
          ↓                                    ↓
      解析入库 → 回到 /shelf          ConflictDialog（模态）
                                               │
                                          稍后处理 → 关闭，角标保留
```

⚠ 04 §3.2 把起点写成「首页 HomeUI」，与 §3.1.1 的引导页冲突。**以本文件为准：起点是引导页，没有独立的「首页」。**
