## 3.1 系统界面的外观设计及其类表示

## 3.2 系统界面流设计

根据"知音漫卷"系统的用例描述以及每个用例的交互图，该Web应用需要有以下一组界面以支持用户的操作。

首页界面"HomeUI"，用户打开应用后展示书架列表，提供导入文档和登录入口。

登录/注册界面"LoginUI"，其职责是帮助用户输入账号密码进行登录或注册新账号。

导入文档界面"ImportUI"，其职责是帮助用户选择并导入EPUB/TXT/Markdown格式的电子书文档。

阅读界面"ReaderUI"，其职责是展示图文混排内容并提供逐句高亮跟读、播放控制、书签等功能。

播放控制界面"PlaybackUI"（嵌入式），嵌入在阅读界面底部，其职责是提供朗读播放/暂停/跳转/语速调节控件。

界面跳转关系：首页→登录/注册界面（点击登录）；首页→导入文档界面（点击导入）；首页→阅读界面（点击书架文档卡片）；阅读界面→首页（返回）；登录成功后自动返回首页。

## 4.4 部署设计

"知音漫卷"系统采用单机部署方式（见图4-9）：由一台普通 Windows 笔记本同时承担前端静态资源、服务端、数据库与语音合成推理服务四个角色，各组件以容器编排或原生方式运行。其中"ZhiYinClient"前端子系统运行于用户的浏览器（Chrome/Firefox/Edge/Safari），负责文档渲染、交互控制、语音播放与高亮同步；"ZhiYinServer"后端子系统运行于该笔记本的 Node.js 20 运行时，提供用户认证、数据同步 RESTful API、文档元数据管理、图片资源代理等服务，并使用 SQLite 数据库保存用户信息、阅读进度、书签与令牌数据（如后续并发写入需求上升，可平滑迁移至 MySQL 或 PostgreSQL）；"TTS 推理服务"运行于同机的 Python 3.11 运行时，默认由自托管的 Kokoro-FastAPI 提供语音合成。同一无线局域网内的平板与手机以"笔记本局域网地址 + 端口"访问前端，即可完整演示跨设备进度同步；局域网之外的公网访问不在本期范围之内。前端不直接对接任何外部服务：语音合成、图片资源与AI 伴读均经服务端代理访问，服务密钥只存放于服务端。
