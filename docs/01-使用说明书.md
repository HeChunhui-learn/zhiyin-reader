# 知音漫卷 使用说明书

软件工程课程设计 · 第一组

---

## 1. 这个软件是什么

一款在浏览器里用的阅读器。把本地电子书导进去，就能：

- **图文混排阅读** —— 插图长在文字对应的位置上，滚到哪加载到哪
- **逐句高亮跟读** —— 一句一句念，念到哪句哪句亮，自动滚动跟着走
- **跨设备续读** —— 在电脑上读了一半，平板打开接着读
- **书签** —— 随手标记位置，多端同步，改冲突了两份都留着

不需要安装客户端，浏览器打开就能用。

---

## 2. 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位）。服务端也可以在 macOS / Linux 上跑 |
| 运行时 | **Node.js 20 或更高版本**（含 npm） |
| 内存 | 8GB 够用，16GB 更稳 |
| 浏览器 | Chrome / Edge / Firefox / Safari 的近年版本 |
| 网络 | 首次装依赖要联网；之后可离线运行 |

不需要 Docker、不需要 Python、不需要数据库服务器。

## 3. 启动

### 3.1 一键启动（推荐）

双击项目根目录下的 **`start.bat`**。

它会自动完成五件事：检查 Node → 装依赖 → 建库并写入演示数据 → 起服务端 → 起前端，最后自动打开浏览器。

> 首次运行要联网装依赖，大约一两分钟。之后再启动只要十几秒。

### 3.2 手工启动

要开**两个终端**：

```bash
# 终端 1 —— 服务端（端口 3000）
cd 项目目录/server
npm install          # 只有第一次需要
npm run seed         # 只有第一次需要：建库 + 写入演示数据
npm run server

# 终端 2 —— 前端（端口 5173）
cd 项目目录/client
npm install          # 只有第一次需要
npm run dev
```

然后浏览器打开 **http://localhost:5173**。

### 3.3 演示账号

```
账号：demo@example.com
密码：demo12345
```

登录后书架上会有一本《人间词话》。也可以自己注册（账号填手机号或邮箱，密码至少 8 位）。

## 4. 六个界面

| 界面 | 怎么进 |
|---|---|
| 引导界面 | 打开应用的第一屏，三个轮播页 |
| 登录 / 注册 | 引导页点「开始使用」，或直接访问 `/login` |
| 书架界面 | 登录后进入。管理文档的地方 |
| 阅读界面 | 在书架上点任意一本书 |
| 播放控制条 | 阅读界面底部常驻 |
| 冲突对话框 | 出现同步冲突时自动弹出，或点阅读界面右上角「同步冲突」 |
| 个人主页 | 书架界面**左上角头像**，或直接访问 `/profile` |
| 阅读时长 | 书架左侧导航的「阅读时长」，或直接访问 `/stats` |

## 5. 基本使用

### 5.1 注册与登录

- 账号：手机号或邮箱
- 密码：至少 8 位
- 「记住我」勾上后，下次打开不用重新登录
- 连续输错 5 次密码，账号会被锁定 15 分钟，界面会提示还剩多久

### 5.2 导入文档

在书架界面点右上角 **「导入文档」**，选本地文件。

支持的格式：

| 格式 | 说明 |
|---|---|
| **EPUB** | 完整支持，含封面、章节、插图 |
| **TXT** | 按空行分段；`第 X 章 / 卷 / 节` 会被识别为标题 |
| **Markdown** | 标题、段落、图片都会解析 |

导入过程全部在浏览器里完成，解析结果再上传到服务端。

**单个文件上限 100MB**。超过会在读取之前就被拦下并给出明确提示（含实际大小），
不会白等半天再失败。

> **同一本书重复导入会被拒绝**，并提示「这本书已经在书架里了」，旁边有「打开它」按钮直接跳过去。

### 5.3 阅读

- 滚动阅读，正文栏最大宽度 720px 居中
- 右上角 **「目录」** 从左侧滑出章节抽屉，点一下跳过去；
  **当前所在章节会高亮**，并随阅读自动切换；点抽屉外面或按 Esc 收起
- 插图在对应的文字位置内联显示，**滚到附近才开始加载**
- 图片加载中显示灰色占位块，失败会给出「图片不可用」和重试入口

### 5.3.1 阅读设置（右上角「设置」）

从右侧滑出的面板，四项设置都会**记住**，下次打开还是这样：

| 设置 | 说明 |
|---|---|
| 主题 | **白天 / 夜晚**。夜晚模式整个应用一起变，刷新后保持 |
| 字号 | 14 ~ 24px 六档。正文和标题一起缩放 |
| 翻页方式 | **滚动**（默认）或 **点击翻页** |
| 阅读背景 | 可以选一张本地图片当阅读区背景 |

**点击翻页**：点正文**左侧**回上一屏、点**右侧**翻下一屏，中间不响应。
点句子仍然会跳到那一句（跟读用），点图片上的重试按钮也仍然重试 —— 不会被翻页吃掉。
两种模式下滚轮和键盘都能用。

**背景图**只存在**这台设备的浏览器里**，不会上传，也不会同步到别的设备；
上限 8MB。夜晚模式下会自动压一层深色蒙版，免得亮壁纸配深色文字看不清。
换电脑或清了浏览器数据就没了，重新选一张即可。

### 5.4 逐句高亮跟读

点底部 **「跟读」** 开始。

| 操作 | 效果 |
|---|---|
| 跟读 / 暂停 | 开始或停下 |
| 上一句 / 下一句 | 移动位置（暂停时也能用） |
| 语速 | 0.5x ~ 2.0x |
| 音色 | 见下 |
| 点正文任意句子 | 停在那一句，出现「继续跟读」提示条 |

**读一句亮一句**，高亮位置和播放的音频是严格对应的，句子会自动滚到屏幕中间。

**音色**下拉按语言分组。本地引擎装了的音色可以直接选；**没装的会灰掉**并标注
「需安装离线音色包」—— 这样你能一眼分清"这个引擎没有这个音色"和"我还没装"。
选中音色与语速会被记住，下次进阅读界面不用重挑。

**关于语音引擎**：默认用本地部署的 Kokoro（需要另外安装）。**没装也没关系** —— 会自动降级成浏览器自带的发声，屏幕底部会显示「已降级为浏览器发声」，跟读功能照常可用。此时音色下拉里列出的是系统自带的中文嗓音，下面附带本地引擎那八个中文音色的灰条。

### 5.5 书签

阅读界面右上角 **「书签」**：

- **加当前位置** —— 把当前读到的位置记成书签。**名字是系统自动取的**，
  取该位置正文的**前 10 个字**（例如「汪淼站在楼顶，望着远…」），
  读到图片段这类没有文字的地方则记成「第 N 段」。把鼠标停在按钮上能先看到将用的名字
- 点书签名 —— 跳过去
- **✎** —— 重命名（回车确认，Esc 取消）
- **✕** —— 删除

### 5.5.1 收藏

书架里把鼠标移到书的封面上，**左上角的 ☆ 点亮就是收藏**。
左侧导航的 **「我的收藏」** 只列收藏过的书。

### 5.5.2 个人主页与头像

书架界面**左上角的头像**进入个人主页，可以：

- **上传头像**（png / jpg / webp，不超过 2MB）或移除。没设头像时显示昵称首字
- **改昵称**（最多 32 字）

演示账号 `demo@example.com` 已经带了一张默认头像。

### 5.5.3 阅读时长

书架左侧导航的 **「阅读时长」** 看统计：累计、今天、本周，以及按书排行，
点书名可以直接跳过去接着读。

只统计阅读界面**可见、且窗口处于聚焦状态**的时间 —— 挂在后台标签页不算，
切出去做别的事也不算。所以这个数字是真实阅读时间。

### 5.6 跨设备同步

阅读进度和书签会自动同步。

**怎么演示**：用两台设备（或两个浏览器窗口）登录**同一个账号**，打开**同一本书**。在一台上读一段，另一台打开时会自动恢复到那个位置。

**进度不会倒退**：如果另一台设备读得更靠前，就用它的；但如果本机自己已经读到更后面，不会被拉回去。

### 5.7 冲突处理

两端都改了同一条书签时会冲突。此时：

1. 阅读界面右上角「同步冲突」出现**红色角标**
2. 点开能看到**双方各改成了什么**
3. 三个选择：**保留本机** / **保留云端** / **两份都保留**
4. 点「应用」，两端就一致了

**数据永远不会被静默丢弃** —— 冲突时服务端默认把两份都留着，你选「保留某一份」才会删掉另一份。

其他两种冲突的处理：

- 一端删除、另一端修改 → **保留修改**，不执行删除，并标注「该设备曾删除此书签」
- 阅读进度不一致 → 按「不回退保护」**自动处理**，不打扰你

## 6. 常见问题

**Q：页面显示「无法连接到服务端」**

服务端没起来。检查那个标着「知音漫卷-服务端」的命令行窗口是否还开着，或者重新跑 `start.bat`。

**Q：跟读没有声音**

先看底部有没有「已降级为浏览器发声」提示。如果有，说明本地语音引擎没启动，正在用浏览器发声 —— 检查系统音量，以及浏览器有没有静音该标签页。

**Q：「图片不可用」**

这张图是在**另一台设备**上导入的，而那台设备还没打开过这本书（图片是按需上传的：只有在本机看到过，才会传到服务端）。回到导入它的那台设备打开这本书、滚到那张图的位置，它就会自动补传上去。

**Q：账号被锁了**

连续输错 5 次密码会锁 15 分钟。等一会儿，或用另一个账号。

**Q：想清空所有数据重来**

关掉服务端和前端，删掉 `server/data` 目录，再跑一次 `npm run seed`。

**Q：长文档滚动卡**

超过 150 段的文档会自动启用「窗口化渲染」，只保留视口附近的段落节点，DOM 规模不随文档长度增长。如果仍然卡，多半是插图过多 —— 图片离开视口时会释放内存，但同一屏内图片太多仍会吃内存。

## 7. 数据存在哪

| 内容 | 位置 |
|---|---|
| 账号、文档、段落、书签、阅读进度、收藏、阅读时长 | `server/data/zhiyin.db`（SQLite 单文件） |
| 上传的原始文件 | `server/data/files/` |
| 已上传的图片 | `server/data/images/` |
| 读者头像 | `server/data/avatars/` |
| 合成的语音缓存 | `server/data/tts/` |
| 登录令牌密钥 | `server/data/.jwt-secret`（首次启动自动生成） |
| 浏览器端的图片 / 音频缓存 | 浏览器的 IndexedDB（换浏览器就没了） |
| **阅读背景图、主题、字号、翻页方式、音色语速** | **浏览器的 localStorage / IndexedDB**（换浏览器就没了） |

**备份就是复制 `server/data` 整个目录。**

## 8. 想用本地语音引擎（可选）

装并启动 [Kokoro-FastAPI](https://github.com/remsky/Kokoro-FastAPI)（默认监听 8880 端口）即可，服务端会自动发现它并把默认引擎切过去，**不用改任何代码**。

如果它在别的地址，起服务端前设环境变量：

```
TTS_BASE_URL=http://127.0.0.1:8880/v1
TTS_API_KEY=            （本地服务一般不用）
TTS_MODEL=kokoro
```

任何提供 OpenAI 兼容 `/v1/audio/speech` 接口的服务都可以替换进来。
