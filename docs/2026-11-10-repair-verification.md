# 审查修复与验证记录

日期：2026-11-10。

## 修复内容

- 书架接入每页 20 本的分页，筛选时重置页码，删除末页最后一本后回退页码；过期搜索响应不能覆盖当前结果。
- 阅读时长失败后只进入离线队列，补报沿用 clientId，避免重新计入下一批；进度与时长的 keepalive 请求检查 HTTP 状态。
- 改密前完成字段校验，密码与昵称在事务中提交，并撤销该读者全部刷新令牌。异步口令计算后重新检查账号状态，防止并发改密和注册竞态。
- 导入参数增加运行时类型、长度和非负索引校验，校验错误返回中文 400。
- 二进制上传改为限量流式落盘，以同目录临时文件原子替换，失败保留旧文件；原始文件下载使用流，图片读取使用异步 I/O。
- 同一文档的上传与删除串行，删除同时清理原始文件与插图。资源目录跟随数据库目录隔离，种子头像也遵循该规则。
- 正文范围读取使用 SQL LIMIT/OFFSET；页面与 EPUB 解析器按需加载，并为页面加载失败提供中文重载入口。
- 冲突弹窗补充标题关联、初始焦点、Tab 循环、Esc 关闭和关闭后的焦点恢复。
- 恢复锁文件中已经声明的客户端依赖，未引入新依赖。
